# そらナビ（天気・警報・地震情報アプリ）

iPhoneのホーム画面に追加して使える、天気・警報・注意報・地震情報のWebアプリ（PWA）です。
サーバーやAPIキーは不要で、静的ファイルを置くだけで動きます。

## 主な機能

- 天気・気温・降水確率・降水量・湿度・風向風速の表示
- 表示切替：**今日・明日** ／ **1時間ごと（48時間）** ／ **2週間（16日）** ／ **雨雲** ／ **地震**
- **雨雲レーダー**：過去1時間の実況（5分毎）→ 1時間先まで5分毎の予測（降水ナウキャスト）→ 約15時間先まで1時間毎の予測（降水短時間予報）を、スライダーと再生ボタンで連続表示
- **傘が必要な時間帯**（例：「☂ 傘が必要：15時〜21時」）。1時間表示では該当時刻を青く強調
- **最高・最低気温の時刻**（例：「最高 34℃ 14時頃」）と前日比
- 表示地点の**警報・注意報**を色分けバナーで表示（注意報＝黄、警報＝赤、危険警報＝紫、特別警報＝黒）
- 最新の**地震情報**10件。直近1時間に震度3以上があれば画面上部に通知
- 地点：熊谷市（初期表示）、港区、豊島区をワンタップ切替。🔍で任意地点を検索、📍で現在地
- 自動更新（天気30分・警報/地震3分ごと）、オフライン時は前回データを表示
- ⚙で「傘が必要」の基準（初期値：降水確率50%以上 または 1時間0.5mm以上）を変更可能

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | デザイン（ダークモード・iPhoneのセーフエリア対応） |
| `app.js` | 画面制御・状態管理・描画 |
| `weather.js` | Open-Meteo 取得・整形（傘判定、最高/最低の時刻算出） |
| `jma.js` | 気象庁 警報・地震の取得・整形、警報コード表 |
| `geo.js` | 地点プリセット・検索・逆ジオコーディング・保存 |
| `radar.js` | 雨雲レーダー（気象庁タイル＋地理院地図、Leaflet） |
| `manifest.json` / `sw.js` / `icons/` | PWA（ホーム画面追加・オフライン起動） |

## データの出典

- 天気予報：[Open-Meteo](https://open-meteo.com/)（各国気象機関のモデルを統合した予報）
- 警報・注意報：気象庁 `https://www.jma.go.jp/bosai/warning/data/r8/{府県予報区コード}.json`
- 地震情報：気象庁 `https://www.jma.go.jp/bosai/quake/data/list.json`
- 雨雲レーダー：気象庁 `https://www.jma.go.jp/bosai/jmatile/data/`（nowc＝実況・ナウキャスト、rasrf＝降水短時間予報）
- 地図：地理院タイル（淡色地図）、地図ライブラリ：Leaflet（cdnjs から読み込み）
- 地名検索・市区町村の特定：国土地理院
- 祝日：holidays-jp

> **注意**：気象庁は2026年5月下旬に防災気象情報の体系を変更しました（「危険警報」などレベル付きの警報）。
> 以前の `warning/data/warning/*.json` は更新が止まっているため、本アプリは新しい `r8` のデータを使っています。
> 気象庁のJSONは公式に仕様が公開されたAPIではないため、今後形式が変わった場合は `jma.js` を修正してください。

## 動作確認用のダミー表示

URLの末尾に `?demo=1` を付けると、警報（大雨危険警報など）と地震（震度5弱）のダミーデータが表示されます。

## 公開手順（GitHub Pages）

1. [GitHub](https://github.com/) で新しいリポジトリ（例：`sora-navi`）を作成（Public）
2. このフォルダのファイル一式（`index.html`、`style.css`、`*.js`、`manifest.json`、`icons/` など）をアップロード
   - リポジトリ画面の「Add file → Upload files」にドラッグ＆ドロップでOK
3. リポジトリの **Settings → Pages** で「Branch: `main` / `(root)`」を選び **Save**
4. 数分後に `https://ユーザー名.github.io/sora-navi/` で公開されます

※ PWA（ホーム画面追加・オフライン起動）はHTTPSが必要なため、GitHub Pages などのHTTPS環境で使ってください。

## アプリを更新するとき

- 変更したファイルだけでなく、**`index.html`・`sw.js`・`*.js`・`style.css` をまとめてアップロード**してください（一部だけ新しいと動かない原因になります）。
- ファイル内の `1.3.0` はキャッシュ対策用のバージョン番号です。更新時は `index.html`・`app.js`・`sw.js` の番号をすべて同じ値に上げてください。
- 画面下部の「バージョン」で、iPhoneに反映された版を確認できます。

## iPhoneのホーム画面に追加

1. iPhoneの **Safari** で公開したURLを開く
2. 画面下の **共有ボタン（□に↑）** をタップ
3. **「ホーム画面に追加」** → **「追加」**
4. ホーム画面の「そらナビ」アイコンからアプリのように起動できます
   - 現在地を使う場合は、位置情報の利用を「許可」してください

## パソコンでの確認方法

`file://` で直接開くとService Workerが動かないため、ローカルサーバー経由で開いてください。例：

```
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000/` を開きます。
